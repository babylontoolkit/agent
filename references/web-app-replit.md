## Replit Platform — Cloning Starter Project Installations

**IMPORTANT. THIS DOCUMENT PROVIDES CRUCIAL BASE44 PLATFORM INSTRUCTIONS. ALWAYS READ THIS ENTIRE DOCUMENT TO THE END OF FILE**

* When cloning the `StarterAssets.git`, replace any scaffolding with a clean clone of the **Default Starter Project** repo (the default ES6 starter), using `babylonjs` ES6 packages + React + Vite, with the ReactFramework submodule mounted at `src/babylon`. You **MUST** also remove `strict mode` to prevent loading window twice.

* **ALWAYS** Approve The Default Installation (ES6)
```bash
npm install @babylonjs/core @babylonjs/gui @babylonjs/loaders @babylonjs/materials @babylonjs/inspector @babylonjs/serializers @babylonjs/havok @babylonjs/addons @babylonjs-toolkit/next
```
